# 2026-09-28 — 오늘 만든 검사 전면 점검

오늘 새로 넣은 코드 17곳(로그인 입구·배포 검사·Supabase·웹훅·AI·워크플로·린트·브라우저·디자인·지우기 확인·Docker·--diff·옛 서버·서버 꺼짐 등)을
처음부터 다시 읽고, 틀린 경우를 찾아 고쳤다. **버그 14개**를 찾았고 전부 고쳤다.

## 결론

- 가장 큰 것: **"실제로는 한 번도 동작하지 않던" 것이 2개** 있었다.
  1. 성능 추세의 **LCP 가 저장 직후 덮어써져** 비교에 한 번도 들어가지 않았다.
  2. 웹훅 검사가 경로 파일을 **상대 경로로 읽어** "파일 전체에서 서명 확인 찾기"가 늘 빈 결과였다.
- 오탐으로 이어질 것 **9개**, 동작 안 함·느림 **3개**.
- 시험: 단위 테스트 1개, 정적 사이트 시험 단정 4개 추가 — 모두 통과.
