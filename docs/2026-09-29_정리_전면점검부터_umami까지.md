## 2. umami 를 돌리며 찾아 고친 것

| 문제 | 원인 | 고침 |
|---|---|---|
| `npm install` 이 `workspace:*` 에서 멈춤 | umami 는 **pnpm** 워크스페이스인데 QA 는 늘 npm 으로 설치 | 잠금 파일(그 폴더부터 위로)·`packageManager` 로 pnpm·yarn·bun 을 골라 설치·빌드·시작·자체 테스트 (PR #40) |
| pnpm 은 됐지만 "pnpm 12.3.4 가 필요하다 (11.24.0)" | 레포가 `engines.pnpm` 로 버전을 못박았다 | 레포가 정한 버전(`engines`·`packageManager`)과 이 맥의 버전이 다르면 **corepack 으로 그 버전을 받아 쓴다** (umami → `corepack pnpm@12.3.4`, outline → `corepack yarn@4.18.0`). 받을지 묻는 창은 끈다 — 이 문서와 함께 올림 |
| umami 를 **크로스핏 설정으로** 검사 | QA 화면에서 크로스핏의 ⚙ 설정 '레포 폴더' 칸에 umami 주소를 넣었다 → 크로스핏 전용 설정(관리자 로그인·공개 경로)으로 umami 를 쟀다 | 크로스핏 폴더를 되돌리고 umami·outline 을 따로 추가. **전용 설정이 있는 프로젝트에 원격 주소가 다른 레포를 넣으면 막고 "[+ 추가] 로" 라고 안내** (PR #40) |
| 고쳤는데도 옛 오류가 그대로 | QA 화면 서버(`node ui.js`)가 오후 5시에 켜진 채 옛 코드로 돌고 있었다 — 브라우저 탭만 닫아서는 안 꺼진다 | 서버를 끄고(`kill`) 다시 켜니 새 코드로 돈다. **코드를 받은 뒤엔 QA 실행 창(터미널)까지 닫고 다시 연다** |
