- **조치:** 리포트에 QA 버전(커밋·커밋 안 한 수정 여부)을 저장하고, 지난 검사와 버전이 다르면 경고를 띄운다 (명령줄·화면·HTML). 단위 테스트 16개 통과.

**Docker 자동 켜기 — 실패**
- 시험: `orb stop` 으로 엔진만 끈 뒤 검사 → "OrbStack: 켰지만 90초 안에 준비되지 않음".
- 원인: `common/deps.js` 가 `open -a OrbStack` 으로 앱만 연다. 앱이 이미 떠 있고 엔진만 멈춘 상태에선 엔진이 켜지지 않는다. `orb start` 를 써야 한다. (앱을 완전히 종료한 경우는 시험 안 함)
- 서버가 안 떠서 이번 두 번 연속 검사는 코드 검사만 돌았다. 코드 검사 부분은 두 번 결과가 같았다.

**Docker 자동 켜기 — 재시험: OrbStack 앱을 완전히 종료한 상태에서는 성공**
- QA 가 OrbStack → `grove-pg` → CrossFit 서버까지 켜고 전체 검사를 돌렸다.
- 엔진만 멈춘 상태(`orb stop`, 앱은 떠 있음)는 여전히 실패 — `orb start` 로 고칠 일이 남았다.

**점수 흔들림 — 같은 QA 버전으로 두 번 연속: 80.9 → 80.9**
- 영역별 검사·통과·문제 수까지 같았다.
- 단, 로그인이 실패해 로그인이 필요한 15개 영역은 둘 다 못 쟀다. 그 영역들의 흔들림은 아직 모른다.

**설정 오류 분리 — 맥에서 동작 확인**
- 로그인 실패 영역이 "설정 오류로 못 잼 (제품 결함 아님)" 으로 빠지고 점수·먼저 고칠 것에 들어가지 않았다.

**새로 찾은 QA 버그**
- QA 버전 경고가 커밋 안 한 수정이 같아도 "다르다" 고 떴다 → 수정 내용의 지문(sha1 앞 7자리)을 남겨 같은 상태끼리는 같게 보도록 고침.
- 리포트 파일명이 분 단위라 같은 분에 두 번 돌리면 앞 리포트를 덮어쓴다. 시험 중 실제로 한 개가 덮어써졌다.
  → 초 단위(`2026-09-27-10-06-25.json`)로 고침. 화면의 "지난 검사" 날짜 표시도 새 이름을 읽게 고침.

**OrbStack 엔진만 멈춘 상태 — 고침**
- `common/deps.js` 가 `open -a OrbStack` 전에 `orb start` 를 먼저 부른다 (엔진이 뜰 때까지 최대 3분 기다림).
- 재시험: 앱은 떠 있고 엔진만 끈 상태에서 QA 가 엔진 → `grove-pg` → 서버까지 켜고 전체 검사를 마쳤다. 제품 점수 80.9 로 앞선 두 번과 같았다.
- QA 자체 테스트 `npm test` 19개 통과.

**CrossFit 로그인 실패 — 설정값 문제**
- QA ⚙ 설정의 관리자 비밀번호가 CrossFit `.env` 의 `ADMIN_PASSWORD` 와 다르다. 그래서 로그인 401 → 로그인이 필요한 검사가 빠졌다.

## 전에 하려다 못 한 것 (대화기록 기준)

**맥에서 확인 못 한 것** — 지금까지 리눅스 작업 환경에서만 확인했다
- Docker 자동 켜기 (Docker Desktop·OrbStack·Rancher Desktop·Colima) — CrossFit(55432 Postgres) 으로 확인
- 화면 로그인·검사 수준·외부 서비스 영역·설정 오류 분리
- 대상 레포용 CI 템플릿(`docs/ci/qa-github-actions.yml`) — 실제 GitHub Actions 에서 한 번도 안 돌림
- Spring·FastAPI·Expo 는 서버를 띄운 검사를 못 해 봤다 (코드 검사까지만 확인)

**점수 신뢰도** (위 순서 1 의 세부)
- 무차별 대입 검사가 설정 계정을 잠그지 않게 — 전용 계정, 또는 잠금 풀릴 때까지 기다리기
- 시간에 따라 흔들리는 판정(느린 API·화면 로딩·응답 속도) — 여러 번 재서 가운데 값, 경계 여유
- △ 가 많이 나오는 검사의 기준 다듬기, 같은 원인끼리 묶어 접어 보이기

**검사 수준 계획 중 남은 것**
- 전문가 수준에서 보안 헤더(HSTS 필수 등)를 더 엄하게
- 자동 생성 입력 개수를 수준에 맞춰 조절 (지금은 화면·버튼 수만 조절)
- 화면 왼쪽 목록에 "이 수준에선 안 보는 영역" 표시

**제안만 하고 안 한 기능**
- 화면 모양 변화 — 지난 검사 스크린샷과 비교해 레이아웃 깨짐 표시
- 역할이 3개 이상인 앱의 권한 표 (관리자·일반·손님)
- 동시 접속 부하
- 결제·메일·문자 외부 연동을 가짜 서버로 흉내 내 끝까지 보기
- 검사 속도 — 브라우저 영역 동시 실행으로 3분대 → 1분대
- 스택 확장 — Vue·Nuxt, SvelteKit, Angular, NestJS, Flask, Rails, Laravel, Go, 모노레포, Expo 웹 모드

**계속 손봐야 하는 것**
