# "AI 토큰 0" 과 "$5~35" 의 근거

README 의 "같은 범위를 LLM 으로 판정하면 1회 약 $5~35" 가 어디서 나왔는지 적어 둔다. **측정이 아니라 추정**이다.

## 이 QA 가 AI 토큰을 쓰지 않는 이유

검사 케이스를 만드는 것도(입력 규칙 × 값 유형), 판정하는 것도(상태 코드·응답 모양·화면 이벤트) 전부 `common/` 의 코드다.
실행 중에 LLM API 를 부르는 곳이 없다 — 그래서 비용이 0 이고, 같은 코드에 돌리면 결과가 매번 같다.

## 같은 범위를 LLM 으로 판정하면

| 가정 | 값 | 근거 |
|---|---|---|
| 한 번 돌릴 때 검사 수 | 약 3,000건 | CrossFit Grove 실측 3,078건 (2026-09-27) |
| 검사 1건을 판정시킬 때 넣는 것 | 약 1,500토큰 | 요청·응답 본문 + 판정 기준 설명 |
| 검사 1건의 판정 답 | 약 150토큰 | 통과/문제 + 이유 한두 줄 |
| 합계 | 입력 약 450만 · 출력 약 45만 토큰 | 3,000 × (1,500 / 150) |

| 모델 | 100만 토큰당 입력 / 출력 | 한 번 |
|---|---|---|
| Claude Haiku 4.5 | $1 / $5 | 약 $7 |
| Claude Sonnet 5 | $2 / $10 | 약 $13 |
| Claude Opus 5 | $5 / $25 | 약 $34 |

- 가격은 Anthropic 공식 API 요금 (2026-06 기준). 판정 기준을 캐시하면 입력 비용이 크게 줄어 Sonnet 기준 $4~5 까지 내려간다 → README 의 범위 **$5~35**.
- 푸시할 때마다 CI 로 돌리면(월 30번) 프로젝트 하나에 월 $100~1,000.
- LLM 판정은 돌릴 때마다 조금씩 달라질 수 있다 — "같은 코드 → 같은 결과" 를 잃는다.

## 한계

- 실제 LLM QA 서비스는 3,000건을 하나씩 묻지 않고 골라서 본다 — 비용은 더 적지만 보는 범위도 좁다. 위 숫자는 **같은 범위를 볼 때** 의 비교다.
- 더 정확히 하려면 CrossFit 결과 한 번 분량을 실제로 토큰으로 세어(`count_tokens`) 이 표를 바꾼다.
