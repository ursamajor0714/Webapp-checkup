## 3. 배운 것 · 기준

- 사용자 지적: **"DB 컨테이너·.env 를 직접 만들라" 는 해결이 아니다** — "딸깍 한 번" 약속이 깨진다. 준비는 QA 가 하고, 버리는 자원만 만들고, 레포 파일·기존 컨테이너·운영 DB 는 건드리지 않는다.
- 비슷한 이름의 비밀(`GITHUB_WEBHOOK_SECRET`)을 채우면 앱이 오히려 안 켜진다 → 비밀은 **견본 파일에 적힌 것만** 채운다.
- 여러 영역이 같이 쓰는 함수(`guardLine`·`request`)를 고치면 **다른 레포로 다시 돌려 부작용을 확인**한다 (umami 재확인).
- 새 코드를 받으면 **QA 실행 창을 닫고 다시 연다** — 옛 화면 서버가 같은 이름의 검사용 컨테이너를 지워 꼬인 적이 있다.
