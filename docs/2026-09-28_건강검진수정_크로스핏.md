## 고친 것 (원인별)

1. **이상한 본문에 500 (111건)** — 원인은 공통 오류 처리기 하나. 깨진 JSON·`"x"`·`null` 본문은 body-parser 가 이미 400 으로 거르는데, `server.js` 오류 처리기가 그 400 을 500 으로 덮어썼다. 4xx 는 그대로 돌려주게 바꿨다. 본문이 없을 때 `req.body` 가 undefined 라 구조 분해에서 죽던 것도 같은 곳에서 빈 객체로 막았다.
2. **없는 id 에 200 (22건)** — 수정·삭제 경로 13곳이 바뀐 행이 있는지 보지 않았다. `stats.js` 가계부 삭제가 쓰던 방식(바뀐 행 0 → 404)을 그대로 적용. 락커·운동복 반납도 없는 id 면 404.
3. **메시지 발송 500** — `content` 가 숫자면 `.trim` 이 없어 죽었다. 문자열이 아니면 400.
4. **음수 금액** — 가격, 체험·드랍인 신청 금액은 음수 거부. 락커 이력은 반납 기록이 환불이라 음수가 정상 → 반납은 0 이하, 배정·연장은 0 이상만 받는다.
   - 덤: 화면에서 가격을 저장하면 금액만 보내는데 그때마다 요금제 이름(label)이 지워지던 버그 수정 (`COALESCE`).
5. **API 실패 시 화면 멈춤 (메인 `/`·방문 `/visit`)** — `utils.js` 에 실패해도 멈추지 않는 `getJson`/`postJson` 을 넣어 두 페이지에서 사용. WOD 를 못 불러오면 안내 문구.
   - 덤: 휴관일이라 서버가 신청을 거절(409)해도 화면엔 "접수 완료"가 뜨던 것 → 거절 사유를 보여 준다.
6. **`document.write` 경고** — 인쇄 팝업을 띄우는 방식이라 그대로 둠. 다만 그 안의 이스케이프 함수가 따옴표를 안 막아 서명 이미지 `src="..."` 로 코드가 끼어들 틈이 있어 공용 `escapeHtml` 로 교체.
7. **X-Forwarded-For 로 로그인 잠금 우회** — 운영(Render)은 프록시 뒤라 원래 안전. 프록시 없는 로컬에서도 헤더를 믿던 것이 문제 → `trust proxy` 는 `NODE_ENV=production` 에서만.
8. **테스트 없음** — `npm test` (`node --test backend/test/*.test.js`) 추가.
